# Hotspot Security Tester

واجهة عربية محلية لفحص أولي لملفات بطاقات Hotspot بصيغة CSV، مع سجل تدقيق محلي باستخدام SQLite.

## الميزات
- واجهة عربية من اليمين إلى اليسار ومتجاوبة.
- فحص الحقول الفارغة وأسماء المستخدمين وكلمات المرور الشائعة ومطابقة اسم المستخدم لكلمة المرور.
- سجل للفحوصات الأخيرة في قاعدة بيانات SQLite محلية.
- حد لحجم الملف، وقبول CSV فقط، ولا حاجة إلى خدمة ذكاء اصطناعي أو إنترنت أثناء التشغيل.

## المتطلبات
- Python 3.10 أو أحدث.
- Flask.

## التشغيل على Windows
افتح CMD داخل مجلد المشروع ونفّذ:

```bat
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

ثم افتح http://127.0.0.1:5000

## الاختبار
ارفع الملف `samples/test_cards.csv` من واجهة التطبيق.

## تنبيهات أمنية مهمة
- هذه الأداة لا تتصل بـ MikroTik ولا تحاول تسجيل الدخول أو تخمين كلمات المرور؛ إنها تفحص ملف CSV يقدمه المستخدم فقط.
- لا تستخدم بيانات حقيقية في العينة التجريبية، ولا تشارك ملفات البطاقات أو كلمات المرور.
- غيّر `SECRET_KEY` قبل أي نشر، ولا تعرض التطبيق على شبكة عامة دون إضافة المصادقة ووسائل حماية مناسبة.
- النتائج مؤشرات أولية وليست تدقيقًا أمنيًا شاملًا.
