# Hotspot Security Tester

أداة ويب محلية بواجهة عربية لإنشاء بطاقات Hotspot تجريبية بصيغة CSV وفحص ملفات CSV الموجودة، مع سجل تدقيق محلي باستخدام SQLite.

## الميزات
- إنشاء عدد من رموز المستخدم العشوائية الفريدة (1–5000) وتصديرها مباشرة إلى CSV.
- تحديد عدد الخانات الرقمية والبادئة الاختيارية واسم Profile.
- إنشاء كلمات مرور عشوائية منفصلة عن أسماء المستخدمين.
- فحص الحقول الفارغة وأسماء المستخدمين وكلمات المرور الشائعة في ملف CSV مرفوع.
- مقارنة أسماء المستخدمين في CSV مع قائمة مستخدمي Hotspot في MikroTik عبر REST API بصلاحية قراءة فقط.
- سجل للفحوصات الأخيرة باستخدام SQLite، وواجهة RTL متجاوبة.

## التشغيل على Windows
```bat
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
ثم افتح http://127.0.0.1:5000

## تنسيق CSV
`username,password,profile`

## حدود الاستخدام
- مولّد CSV ينشئ بيانات عشوائية جديدة؛ لا يستنتج أنماطًا من بطاقات حقيقية ولا يولّد قوائم احتمالات لتخمين كلمات المرور.
- ميزة MikroTik تقرأ قائمة مستخدمي Hotspot فقط عبر REST API؛ لا تجرب كلمات المرور ولا تنفذ تسجيل دخول تلقائيًا.
- أنشئ حساب API مخصصًا بأقل صلاحيات قراءة لازمة. لا تستخدم حساب الإدارة الرئيسي، ولا تعرض REST API للإنترنت.
- يفضّل HTTPS بشهادة موثوقة. لا تعطّل التحقق من الشهادة. بيانات API لا تُخزّن في قاعدة بيانات التطبيق.
- استخدم المولّد لبطاقات تملك صلاحية إنشائها، وتأكد من إعدادات Profile في جهازك قبل استيراد الملف.
- غيّر `SECRET_KEY` قبل أي نشر، ولا تعرض التطبيق على شبكة عامة دون إضافة المصادقة والحماية المناسبة.
- نتائج الفحص مؤشرات أولية وليست تدقيقًا أمنيًا شاملًا.
